Site institucional desenvolvido para apresentar a **Tiny Care**, uma proposta de serviço de perfuração humanizada, com foco no acolhimento, na segurança e na divulgação de serviços na área da saúde.

O projeto foi desenvolvido no contexto de um **trabalho acadêmico universitário de Enfermagem**, com o objetivo de transformar uma proposta de negócio em uma interface web informativa, moderna e responsiva.

## 📌 Sobre o projeto

O Tiny Care é uma landing page institucional que apresenta serviços de perfuração humanizada, informações sobre a equipe, diferenciais do atendimento e canais de contato.

A interface foi projetada com foco na organização das informações, na navegação intuitiva e em uma identidade visual acolhedora, utilizando elementos gráficos, cores e componentes interativos.

O desenvolvimento priorizou a experiência do usuário, a adaptação para diferentes tamanhos de tela e a apresentação clara dos conteúdos.

## ✨ Funcionalidades

- **Layout responsivo:** interface adaptável para dispositivos móveis e desktops.
- **Navegação por seções:** menu com links internos para facilitar o acesso às informações.
- **Apresentação de serviços:** seções informativas sobre os diferenciais e serviços da Tiny Care.
- **Equipe:** apresentação dos profissionais e de suas respectivas funções.
- **Carrossel de depoimentos:** navegação interativa entre avaliações ilustrativas.
- **Formulário de contato:** campos de entrada, formatação automática de telefone e confirmação visual de envio.
- **Animações e efeitos visuais:** transições, efeitos de hover e elementos animados.

> **Nota:** o formulário de contato possui comportamento demonstrativo no front-end. Não há integração com backend para envio ou armazenamento de mensagens.

## 🚀 Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/wan-rodrigues/site-tiny-care.git
```

**2. Acesse o diretório:**

```bash
cd site-tiny-care
```

**3. Abra o arquivo `index.html` no navegador.**

Não é necessário instalar dependências ou configurar um servidor backend. A página utiliza bibliotecas externas carregadas por CDN, sendo recomendável uma conexão com a internet.
